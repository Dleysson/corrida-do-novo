# Corrida do Novo — Circuito 2027

Landing page oficial do circuito de corridas de rua **Corrida do Novo** (Novo Atacarejo).

## 🚀 Funcionalidades

- **Duas Abas de Inscrição:**
  - **Venda Geral:** Inscrições abertas para o público geral (5KM, 10KM, 15KM).
  - **Colaborador Novo:** Área e valores exclusivos com validação de matrícula/CPF para colaboradores do Grupo Novo Atacarejo.
- **Seletor Dinâmico de Cidades:**
  - **Maceió** (28 de Fevereiro)
  - **Recife** (31 de Janeiro)
  - **João Pessoa** (21 de Março)
  - Atualização em tempo real da faixa de data oficial, kit do corredor (camisa, medalha, número de peito), cronômetro regressivo e links Evenyx.
- **Modal de Inscrição:** Pop-up para direcionamento rápido entre Venda Geral e Colaborador.
- **Informações de Prova:** Acordeão com detalhes da prova, regulamento e retirada de kits.

## 🛠️ Tecnologias

- HTML5 Semântico
- CSS3 Moderno (Custom Properties, Flexbox, Grid, Responsividade)
- JavaScript Vanilla
